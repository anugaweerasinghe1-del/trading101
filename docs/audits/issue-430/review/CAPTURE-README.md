# Reading the capture evidence

All page, browser, bank and interaction observations in this bundle were collected anew on14November2026. Historical material was used only to discover routes and reuse collector code. Raw collector fields such as pass1/pass2 remain null: collection does not perform editorial review. The annotated editorial-block-records.jsonl.gz, page/case/supplement assessments and CSV dispositions contain the review decisions.

A REVIEWED block means its content was considered; it does not mean that an associated HUMAN-REVIEW finding was accepted or that Google approved the page. Identical and parameterized shared-template references are explicit. Dynamic values are recorded snapshots, not all future states. Original and repaired versions are retained with distinct evidence paths and hashes.

The independent second pass was by the same Codex assistant, not an independent human. Native deployment receipts identify exact protected merges; a successful build or a preview badge alone is not used as production identity. Credentials and unrelated provider billing/usage records are excluded.

The full third-party policy/source texts are not republished. Dated URLs, hashes, substantive cross-check summaries and access limitations accompany the report. Tool setup failures that did not reproduce product defects are distinguished in the live recheck evidence.
