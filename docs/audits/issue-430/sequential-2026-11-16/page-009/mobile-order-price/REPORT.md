# P09 mobile order estimate wording

**STRICT-TRADE-008** is a confirmed product-copy mismatch. Current mobile drawers promised an immediate fill at the displayed simulator price. The active desktop panel describes the price as approximate.

A disposable PostgreSQL database applied the checked-in migrations through the repository's isolated backend setup. An eligible $100 AAPL quote served as the preview reference. After that value was replaced by an eligible $101 quote, the normal signed-in practice RPC returned a $101 fill, a $0.202 fee and a $202.202 total for two units. A separate stale quote was rejected. The public browser observations and the local PostgreSQL fixture have separate scopes. No production account or quote was written. [Before-edit evidence](https://github.com/anugaweerasinghe1-del/trading101/issues/430#issuecomment-6967439344)

The corrected mobile copy describes an estimate and discloses that signed-in orders may use a changed price or pause when a quote is unavailable. It changes one text block. TypeScript and the Cloudflare build passed. Chromium verified the two mobile routes and the unchanged approximate desktop copy. The candidate still requires exact GitHub checks, native Cloudflare production verification and a public reread.
