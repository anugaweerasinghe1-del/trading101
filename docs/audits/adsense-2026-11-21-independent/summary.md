## New site defect and patch

**THQ-IND-20261121-001 (P2):** `/learn/trade-review` was a direct-entry production 404. `src/App.tsx` declares the route, `src/pages/Trade.tsx:292` and `src/pages/Portfolio.tsx:483` link to it, and `src/pages/TradeLearningReview.tsx` implements it. However, no static entrypoint was generated by `scripts/routes.ts`, the narrow Pages Functions include list omitted it, and the safe SPA fallback did not permit it. The fix adds an explicit **noindex** route in `scripts/routes.ts` and checks compiled direct-entry HTML, canonical, robots and sitemap exclusion in `scripts/verify-retention-learning-loop.ts`. This avoids expanding privileged function routing, ads, auth or trading state.

Status: **FIXED_IN_CODE on audit branch; PR tests, merge and Cloudflare production recheck are required before VERIFIED_PRODUCTION**. See findings ledger for discovery and evidence. The code patch is separate from site-wide claims.
